## 这是什么

**《麦门人生回忆录》**——基于麦当劳中国官方 MCP，把你的真实订单、积分、优惠券、抽奖记录，装订成一本 **18 页可翻阅、可互动的书**：

|              |                                                 |
| ------------ | ----------------------------------------------- |
| 🌱 **开卷三问**  | 翻开之前先被问住："60% 的麦门人生，你给了同一个四件套。这是专一，还是固执？"       |
| 📖 **章节叙事**  | 「那一次出走」「精算师时刻」——每一章都是一个真实订单的故事                  |
| ⏰ **麦门生物钟**  | 你的中位点餐时间 + 24h 时间带状图，"你的指针，比地铁还准"               |
| 🪪 **人格鉴定书** | 四维雷达 + 称号 + 麦力值，盖钢印的那种证书                        |
| 🌷 **积分花园**  | 过期积分没有消失——它们开成了花。**浇水互动**，全部浇完解锁隐藏句："看，浪费也能开花。" |
| 🏅 **节气勋章墙** | 金币压印风勋章 + 隐藏款「麦门全知者」收集进度                        |
| 📕 **麦门文学**  | 每次打开随机一句，⟳ 重掷，句句挂着你的真实数据                        |
| 🔍 **失踪人口**  | "你已经 33 天没有推开那扇门了。而你的历史平均，每 12.3 天就要见一次。"       |
| ⚖️ **汉堡天平**  | 原价人生 vs 麦门实付，真实比例——金色那一段是你省下的钱                  |
| 🎫 **后记**    | 卡包里的券是"下一章的入场券"，在 WorkBuddy 里说一句话就能开吃           |

**从 2 单到 200 单，每人拿到的是不同的书**——20+ 项页面级兜底，数据少会变成另一本同样完整的故事。

## 它不是年报，是一本书

数据报告已经很多了（这次比赛里就有很多优秀的）。所以先说清楚不同点在哪：

| 常见年度报告           | 麦门人生回忆录                         |
| ---------------- | ------------------------------- |
| 图表堆叠的统计页         | 章节化叙事：有封面悬念、有章节、有后记             |
| 数据 → 标签（"你是深夜党"） | 数据 → 故事（"8月14日，你出走了一次，去了北苑秋实路"） |
| 看完即走             | 文学页每次打开不同、勋章墙通向隐藏款、花园等你浇水       |
| 把消费行为贴个 MBTI     | 麦力值四维雷达 + 钢印鉴定书                 |
| 只夸你              | **先让你认罪（忏悔室五宗罪），再赦免你（看在钱的份上）**  |
| 把过期积分写成一行灰字      | **积分花园**：1135.6 分变成了看得见的花，还能浇水  |
| 2 单用户生成同样的空壳     | 用户分型 + 每页兜底：新手拿到"轻量版"，同样是一本完整的书 |

> 我们的设计铁律：**数据可以缺席，叙事不能缺席。** 缺数据的页面降级为另一段故事（"你至今没有走出过这一家。也许有一天，也许永远不。"），而不是显示"暂无数据"。

## 快速开始

### 方式一：在线阅读（零安装，30 秒）

打开 **[Demo 版回忆录](https://whxb69.github.io/mcd-memoir/)**，用 demo 账号的数据先翻一遍。

### 方式二：生成你自己的书

```bash
git clone https://github.com/whxb69/mcd-memoir.git
cd mcd-memoir

# 1. 申请 MCP Token（免费）：https://mcp.mcd.cn → 登录 → 控制台 → 激活
# 2. 采集你的数据（只读，8 个查询类工具）
MCD_MCP_TOKEN=你的Token python3 gather.py
MCD_MCP_TOKEN=你的Token python3 fetch_details.py
# 3. 装订成书
python3 build_book.py
# → book.html，浏览器打开，往下翻
```

需要 ≥2 单历史订单（不足会拒绝并提示"先去吃一顿"）。**全程只读、本机渲染，数据不出你的电脑。**

### 方式三：WorkBuddy 一句话生成

在 [WorkBuddy](https://www.workbuddy.cn) 配置麦当劳 MCP（见 [`mcp-config.example.json`](./mcp-config.example.json)），然后对 AI 说：

> 「帮我把我的麦当劳订单做成一本回忆录」

## 架构

```
gather.py         采集层   order-list / query-my-account / coupons / prizes / nutrition
fetch_details.py  详情层   逐单 query-order（官方商品图·原价·实付·券名·套餐子项）
stats.py          画像层   陪伴天数 / 时段 / 忠诚比 / 营养换算 —— 本地确定性计算
fallback.py       兜底层   用户分型（novice/regular/veteran）+ 每页渲染决策
build_book.py     装订层   章节编排 + 规则金句库 + 动森风花园 + 翻页书 HTML
```

## 设计原则

1. **数值不进 LLM** —— 所有金额、积分、日期直接来自 MCP 原始返回；叙事由规则模板生成，模板里的每个数字都绑定数据字段
2. **降级即叙事** —— 任何数据缺失，页面变成另一段故事，绝不显示"暂无数据"；构建末尾 bad-text 硬校验，命中即拒绝发布
3. **只读不写** —— 全链路仅调用查询类 Tool，不碰下单/领券/抽奖等任何写操作
4. **本机渲染** —— 数据不出本地，无上传、无第三方服务

## 目标用户

- **麦门信徒**：想知道自己吃成了什么样的人（剧透：会被看穿）
- **Wrapped 年报爱好者**：想要一份**会讲故事**的版本，而不是几张图表
- **爱晒的人**：花园、忏悔室、鉴定书——每一页都是做好的社交素材
- **MCP 开发者**：一个"个人数据 → 叙事产品"的完整参考实现（含兜底工程）
